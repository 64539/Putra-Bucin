# Putra-Bucin 💌

A mobile-first, aesthetic, and interactive romantic web application specially made for **Fathiyyah**, celebrating their anniversary (**22 Agustus 2025**).

Built with **Next.js 14**, **React 18**, **Tailwind CSS**, and **Framer Motion**.

---

## ✨ Features

1. **Passcode Screen (Lock Screen)**
   - iOS-style number keypad with tactile clicks and haptic vibration.
   - Secret Passcode: `220825` (Anniversary Date).
   - Shake animation on incorrect PIN entry.
   - Confetti celebration and smooth fade-out transition on unlock.

2. **Music Player (BGM)**
   - Song: *"Monokrom"* by Tulus.
   - Floating corner UI toggle with rotating vinyl disc and live sound-wave equalizer animation.
   - Play, pause, and mute controls.

3. **3D Envelope & Letter Reveal**
   - 3D realistic envelope with wax seal stamp.
   - Pulsing hint: *"Tap untuk membuka 💌"*.
   - Spring physics flap opening and letter sliding animation.
   - Specifically addressed to **Fathiyyah** with full-screen reading modal.

4. **Live Love Counter**
   - Real-time elapsed time counter (Days, Hours, Minutes, Seconds) since 22 Agustus 2025.

5. **Polaroid Gallery Reveal**
   - Mystery gift box cards that flip with 3D animation upon clicking.
   - Displays romantic photo moments with handwritten captions.
   - Photo lightbox modal for detailed view.

6. **Timeline Cinta**
   - Vertical glowing milestone timeline (*Awal Kenal*, *Kencan Pertama*, *Hari Jadian: 22.08.2025*, etc.).
   - Fluid scroll-triggered animations via Framer Motion `whileInView`.

7. **Message Jar (Kocok Toples)**
   - Interactive 3D glass jar with floating glowing origami stars.
   - Shaking animation on click with confetti burst.
   - Reveals romantic quotes and reasons why Putra loves Fathiyyah.

8. **Ambient Floating Hearts**
   - Subtle glowing bokeh and drifting heart particles in a dark-romantic color palette (deep rose, dark plum, and soft blush pink).

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **UI & Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Effects**: [canvas-confetti](https://www.npmjs.com/package/canvas-confetti)

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/64539/Putra-Bucin.git
   cd Putra-Bucin
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser (preferably on mobile or in mobile responsive mode).
